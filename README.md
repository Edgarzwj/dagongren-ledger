# 打工人小账本

一个**单文件、零依赖、离线可用**的个人记账 & 真实时薪工作台。所有 CSS / JS / SVG 图标全部内联，不依赖任何 CDN、后端或在线图表库，双击 HTML 即可在浏览器运行。

## 功能
- **真实时薪计算器**：综合到手月薪、发薪月数、工作成本、在场时间、通勤、加班，逐步展开公式算出时薪
- **10 秒记账**：金额 / 分类 / 备注，保存后立刻换算「这笔钱 ≈ 你工作 X 小时 Y 分钟」
- **首页概览**：本月收入 / 固定支出 / 弹性支出 / 净结余，最近 4 笔，原生 SVG 存款曲线
- **自由基金 & 安全垫**进度
- **情景模拟**：通勤优化 / 减少加班 / 涨薪 对时薪与自由时间的影响
- **数据**：localStorage 本地保存，JSON 导入导出 + CSV 导出 + 安全清理示例数据

## 使用
直接用浏览器打开 `打工人小账本.html` 即可。手机上可把文件部署成网页后「分享 → 添加到主屏幕」当 APP 用。

## 隐私
数据仅保存在本机浏览器，不上传任何服务器。建议常点「导出 JSON 备份」。
