# 打工人小账本 (Dagongren Ledger)

> 一个**单文件、零依赖、真·离线**的个人记账工作台。它不只记「花了多少钱」，更把每笔支出换算成「你工作了多少小时」——让钱和时间都看得见。

## 它解决什么问题

普通记账 App 只回答「钱去哪了」。但打工人的真实焦虑是**时间被明码标价**：通勤、加班、低时薪，正在悄悄吃掉你的生命。

打工人小账本把「记账」和「时薪」拧成一条线：

- 算出你的**真实时薪**（扣掉工作成本、通勤、加班后，每小时到底值多少）
- 每记一笔支出，立刻知道「这是你**工作 X 小时 Y 分钟**换来的」
- 用**情景模拟**告诉你：少通勤 30 分钟/天、少加班、涨薪 10%，分别能拿回多少时薪和自由时间

## 核心特性

- **真实时薪计算器**：到手月薪、发薪月数、工作成本、在场时间、通勤、加班，逐步展开公式算出时薪
- **10 秒记账**：金额 / 分类 / 备注，保存后立刻换算「这笔 ≈ 工作 X 小时 Y 分钟」
- **命价本（核心主张）**：首页把本月消费按真实时薪换算成「你卖出的工作生命（天）」——看清这个月为消费打了几天工，而不是为你自己。
- **首页概览**：本月收入 / 固定支出 / 弹性支出 / 净结余，最近 4 笔，原生 SVG 存款曲线
- **自由基金 & 安全垫**：进度条可视化你的财务缓冲
- **情景模拟**：通勤优化 / 减少加班 / 涨薪，对时薪与自由时间的影响
- **可编辑记录**：每笔都能「编」改金额 / 分类 / 备注 / 日期，支出自动重算工时
- **分类预算 + 预警**：每月每类设上限，超支或达 80% 在首页红 / 黄提醒
- **支出分类饼图**：首页原生 SVG 环形图，直观看钱花在哪
- **四维筛选**：按月份 + 类型 + 分类 + 关键词组合查记录
- **数据安全**：localStorage 本地保存，JSON 导入导出 + CSV 导出 + 安全清理示例数据

## 与同类项目的差异化

市面上的方案分两类，我们做中间的闭环：

- **纯记账类**（ExpenseTitan、Expense_Manager、ZyPLJ/bookkeeping、Cloud-Ledger）：只记钱，没有「时间价值」视角。
- **纯实时工资类**（PayDance、realtime-salary-calculator、salary-timer、DevKitLab salary-ticker）：只算工资跳动，不记支出。
- **我们**：记账 + 时薪 + 工作小时换算 + 情景模拟，形成「钱 ⇄ 劳动时间」闭环；再把消费翻译成「卖出的生命」，让你看清被租用的代价——工资计时器在庆祝赚钱，我们在算你卖了多少命。
- **真·离线**：很多同类用 Chart.js（CDN），断网图表就崩；我们全部内联 SVG，**零外链、断网可用**。
- **单文件零依赖**：所有 CSS / JS / SVG 内联，双击即用，不引框架、不调外部 API。

## 快速开始

直接用浏览器打开 `打工人小账本.html` 即可。手机上可部署成网页后「分享 → 添加到主屏幕」当 APP 用。

## 项目结构（存放规范）

```
dagongren-ledger/
├── 打工人小账本.html     # 唯一产物：单文件应用（零依赖、全内联、真·离线）
├── README.md            # 中文文档
├── README_EN.md         # English documentation
├── LICENSE              # MIT
├── docs/
│   ├── ROADMAP.md       # 迭代路线（吸收自同类项目 + 我们的创新）
│   ├── ARCHITECTURE.md  # 单文件架构与铁律
│   └── CHANGELOG.md     # 版本记录
└── assets/              # 预览截图 / PWA 图标（当前全内联，留占位）
```

规范要点：

1. 应用本体永远是一个 HTML 文件；新功能全部内联进该文件，**不引入构建步骤、不引外部 CDN / 框架**。
2. 版本用 Git Tag（如 `v1.0.0`）+ GitHub Releases 发布，`docs/CHANGELOG.md` 记录。
3. 文档中英文两份；应用内文案以中文为主（目标用户），后续可加 i18n。
4. 开源协议 MIT，与主流同类一致，便于传播与二次开发。

## 数据安全与隐私

数据仅保存在你本机浏览器，**不上传任何服务器**。建议常点「导出 JSON 备份」。换浏览器 / 清缓存会丢数据，请注意备份。
