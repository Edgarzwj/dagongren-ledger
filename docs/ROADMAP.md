## 二、核心主张与定位（差异化护城河）

**核心主张**：把「花钱」翻译成「卖命」。不是鼓励你多赚，而是让你看清——这个月你卖了多少天的工作生命，全换成了那些明天就不记得的花销。市面上的工资计时器（PayDance 等）在庆祝「你又赚了 ¥X」，那是老板的视角；我们要做反过来的诚实账本。

1. **闭环 + 生命账本**：记账 + 真实时薪 + 工作小时换算 + 情景模拟 = 「钱 ⇄ 劳动时间」；再把消费聚合成「卖出多少天命」，让每笔花销显露出真实生命代价（I2 命价本 / I6 拿回的生命）。
2. **真·离线**：全内联 SVG，零外链。同类多用 Chart.js(CDN)，断网图表直接崩——这是我们的硬优势。
3. **单文件零依赖**：所有 CSS/JS/SVG 内联，双击即用，不引框架、不调外部 API（如节假日 API）。
4. **主动留白**：I1 实时工资挂件、I4 加班量化属「庆祝赚钱」视角，与主张相悖，**明确不做**，差异化留给友商。

## 三、待吸收特性（来自同类，按优先级）

## 四、我们的创新点（围绕「钱 ⇄ 劳动时间」）

- **I1 实时工资小组件**：常驻"今日已赚 / 当前真实时薪 / 离下班 X 小时"。—— **不做**（庆祝赚钱视角，与核心主张相悖）。
- **I2 生命账本视角**：月度汇总"这个月你用 N 天生命换了这些东西"，强化时间价值。—— ✅ v1.2.0（命价本卡片）。
- **I3 下班倒计时 + 老板键**：隐私模糊（DevKitLab 思路），适合办公摸鱼场景。—— 待定（与主张弱相关，可后续评估）。
- **I4 加班量化**：进入"加班模式"实时显示"这小时你的真实时薪降到 ¥Z"。—— **不做**（庆祝赚钱/加班视角）。
- **I5 财务自由倒计时**：当前存款 vs 自由基金/安全垫目标 → "还有 X 月达到自由基金目标"（FIRE-lite）。
- **I6 拿回的生命**：情景模拟结果用"天数/年"而非仅"小时"表达，更冲击。—— ✅ v1.2.0（模拟结果已改天/年）。

## 五、分阶段实施建议

- **Phase 1（夯实）**：P1 四项（编辑、预算预警、饼图、筛选增强）——低成本、体验立刻变完整。
- **Phase 2（差异化）**：P2（日历/热力、自定义分类、剩余天数、深色）+ I1 / I4 / I6（实时工资小组件、加班量化、生命天数表达）。
- **Phase 3（可选）**：P3 + I2 / I3 / I5（实物换算、老板键、自由倒计时）+ 可选加密同步（明确标注 opt-in，不破坏离线默认）。
