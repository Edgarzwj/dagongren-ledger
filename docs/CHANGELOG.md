# 更新日志 (Changelog)

## v1.2.0 (2026-08-11)
- 确立项目核心主张：**把「花钱」翻译成「卖命」**。首页新增「命价本」卡片，把本月消费（弹性 + 固定）按真实时薪换算成你卖出的工作生命（天），直接回答「这个月你为消费打了几天工」。
- 情景模拟结果改以「拿回的生命（天/年）」表达（原「小时」）：少通勤 30 分钟/天 ≈ 每年拿回 12 天命；少加班 1 小时/天 ≈ 24 天；涨薪 10% ≈ 少卖 30 天命。
- 主动留白：明确**不做**「实时工资挂件 / 加班量化」等「庆祝赚钱」视角功能——那是老板的叙事，与「看清被租用」的主张相悖，差异化留给友商。
- 定位收口为「钱 ⇄ 劳动时间」闭环 + 生命账本视角；GitHub 上暂无以此为核心信条的项目。

## v1.1.0 (2026-08-11)
- P1 全部落地（吸收同类项目验证过的体验项，围绕「钱 ⇄ 劳动时间」闭环打磨）：
  - **可编辑记录**：每笔记录新增「编」按钮，弹窗改金额/分类/备注/日期，支出自动重算工时，编辑后示例标记转用户数据。
  - **分类预算 + 超标预警**：记账页可设每月各类支出上限；首页「本月分类预算」进度条；超预算/达 80% 在「今天要处理」红/黄预警。
  - **支出分类饼图**：首页原生 SVG 环形图（stroke-dasharray 画法，单分类占满也不崩），含金额与占比图例。
  - **筛选增强**：记录列表支持「月份 + 类型 + 分类 + 关键词（备注/分类）」四维组合筛选。
- 导出/导入/清空均兼容新增的 budgets 字段，向后兼容旧备份。
- 预置示例预算数据（与示例记录一并可一键安全清理）。

## v1.0.0 (2026-08-11)
- 初始公开版本：单文件离线记账工作台
- 真实时薪计算器（综合到手月薪 / 发薪月数 / 工作成本 / 在场时间 / 通勤 / 加班，公式逐步展开）
- 10 秒记账（保存即换算「这笔 ≈ 工作 X 小时 Y 分钟」）
- 首页概览：本月收入 / 固定支出 / 弹性支出 / 净结余，最近 4 笔，原生 SVG 存款曲线
- 自由基金目标 & 安全垫进度条
- 通勤 / 加班 / 涨薪情景模拟（时薪与每年拿回的自由时间 / 多赚的钱）
- 数据安全：localStorage、JSON 导入导出、CSV 导出、安全清理示例数据、二次确认清空
- 手机端优化：viewport-fit、apple-mobile-web-app、touch-action、text-size-adjust、内联 SVG 图标替换 emoji
- 工程化：中英文双 README、MIT 协议、项目目录规范（docs/ 路线图与架构铁律）
